# Entity Control

## English

Entity Control gives pack authors and server administrators visual tools for mob spawning, encounter rules, and combat testing.

- Spawn profiles, biome spawn tables, and advanced spawners.
- Entity attributes, combat resets, and block-break encounters.
- Testing dummies, equipment presets, and damage/DPS displays.

Supports Minecraft **1.20.1 / Forge 47.4.2+** and **1.21.1 / NeoForge 21.1+** (validated with 21.1.252). Requires **Java 21** and **KineticCore 26.10.3+** matching the Minecraft/loader. Install required mods on the server and connecting clients. **26.1.2 is reserved and disabled, not supported.**

Optional: Jade 11+ / Curios 5.10+ on Forge, or Jade 15+ / Curios 9.x on NeoForge.

## 简体中文

Entity Control 为整合包作者与服务器管理员提供生物生成、遭遇战规则和战斗测试的可视化工具。

- 生成配置档、群系刷怪表与高级刷怪笼。
- 实体属性、战斗重置与方块破坏遭遇。
- 测试假人、装备预设及伤害和 DPS 显示。

支持 Minecraft **1.20.1 / Forge 47.4.2+** 与 **1.21.1 / NeoForge 21.1+**（验证使用 21.1.252），必需 **Java 21** 和与 Minecraft、加载器匹配的 **KineticCore 26.10.3+**。服务端与连接的客户端均安装必需模组。**26.1.2 仅预留、未启用，不代表支持。**

可选：Forge 使用 Jade 11+、Curios 5.10+；NeoForge 使用 Jade 15+、Curios 9.x。
