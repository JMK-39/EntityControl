# Entity Control

> V1.0

## 简体中文

集中管理生物生成、实体属性、战斗规则和测试假人。

### 核心功能

- 按实体、维度、生物群系等条件控制自然生成，并编辑群系刷怪表和刷怪笼。
- 设置破坏指定方块后生成实体的条件与参数。
- 按规则调整实体属性与状态效果，并控制实体/Boss 战斗重置。
- 提供可编辑装备与属性的伤害测试假人。

### 使用

按 **F6** 进入 Entity Control 的对应管理页面。生成规则与测试假人管理由服务端处理，修改需要权限。

### 前置依赖

必需：Forge 47.4.2+、KineticCore 26.9.20+；可选：Jade 11.0.0+、Curios 5.10.0+。

## English

Centralizes mob spawning, entity attributes, encounter rules, and testing dummies.

### Features

- Control natural spawning and edit biome spawn lists and spawners by entity, dimension, biome, and other conditions.
- Spawn entities when configured blocks are broken.
- Modify entity attributes and status effects and configure entity/boss encounter resets.
- Use damage-testing dummies with editable equipment and attributes.

### Usage

Press **F6** and select the relevant Entity Control page. Spawn rules and dummy administration are handled by the server and require permission to edit.

### Requirements

Required: Forge 47.4.2+, KineticCore 26.9.20+. Optional: Jade 11.0.0+, Curios 5.10.0+.
